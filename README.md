# World Cup Database

A PostgreSQL database project developed as part of the [freeCodeCamp Relational Database Certification](https://www.freecodecamp.org/learn/relational-database/).

## Overview

This project stores and analyzes FIFA World Cup match data using PostgreSQL, Bash scripting, and SQL queries.

## Project Structure

- `worldcup.sql` – PostgreSQL database dump.
- `insert_data.sh` – Bash script to import World Cup match data into the database.
- `queries.sh` – SQL queries executed through Bash to generate statistical insights.

## Technologies

- PostgreSQL
- SQL
- Bash
- Linux

## Features

- Relational database design.
- Automated data insertion using Bash.
- Statistical analysis of World Cup matches.
- SQL queries using aggregations and joins.
